# Crate Dig — downloads

Installers for [Crate Dig](https://cratedig.lemonsqueezy.com). Every release is on the
[Releases page](https://github.com/mooniethegreat/crate-dig-releases/releases/latest).

| Platform | File |
| --- | --- |
| Windows 10/11 | `Crate-Dig-Setup-<version>.exe` |
| macOS 11+ (Apple Silicon) | `Crate-Dig-<version>-arm64.dmg` |
| macOS 11+ (Intel) | `Crate-Dig-<version>-x64.dmg` |

Install, then paste the license key from your receipt on the first screen.
One key works on two machines; free a slot from Settings → License.

The app checks this page for updates on its own. The `latest*.yml` files are
what the updater reads. This repository holds builds only, no source.
